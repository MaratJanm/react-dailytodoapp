Daily Todo: A lightweight React+Vite app for managing daily tasks that auto-reset completions every day to build habits.
Key features:

Progressive tasks: Auto-increment numbers daily (e.g., "Do 10 pushups" becomes 11 tomorrow, +N/day customizable).
Theme toggle: Light/dark modes with system detection.
Storage: Browser localStorage only—no backend needed.
Backup: Import/export tasks as JSON.
Full editing: Add, complete, edit, delete tasks easily.

Built with React hooks, no external deps. Great for personal use or as a starter project!
